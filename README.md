### 你好，我是 Albert

下面是我用 Claude Code 独立做的几个开源小工具。

| 项目 | 做什么 | 看点 |
|---|---|---|
| [**声档**](https://github.com/Albert-ycc/meeting-stack) | 本地会议录音工作台：录音自动转写归档，AI 从纪要里抽任务，人工确认后才进待办 | 音频和逐字稿不出本机，转写用本地模型 |
| [**伴读**](https://github.com/Albert-ycc/reading-companion) | 边读 PDF 边问 Claude：划线即提问，导读要点都能跳回原文出处 | 发布前全量测试整理缺陷 121 条，修复并复测 96 条 |
| [**prompt-polish**](https://github.com/Albert-ycc/prompt-polish) | Claude Code 插件：把随手写的草稿改写成完整提示词 | 12 条留出草稿盲评，新版平均名次 2.17、旧版 3.46，编造 0 条 |
| [**figma-eye**](https://github.com/Albert-ycc/figma-eye) | 在 Figma 里给原型留评论，Claude 在后台改稿，改完在原评论下回帖 | 说不清要改什么时不动画布，先回帖反问；回帖写明改了哪一屏、原值和新值 |
| [**Origin Workbench**](https://github.com/Albert-ycc/origin-workbench) | 把团队协作的多 Agent 平台改成单人本地工作台 | 三个多月发布 31 个版本 |
